# introduction
okay so its a pcb you can put on a string (i have no idea how to explain knotting so look up your own style i guess) <br>
## how to use
insert the CR2032 battery you can get in any random stuff store into the holder (the 3d model for the thing is wrong but they're hooked up exactly the same as the one you get) <br> click the button to toggle it on or off you'll feel a slight vibration as you hold down the button <br>
